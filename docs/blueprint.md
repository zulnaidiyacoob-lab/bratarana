# **App Name**: Castleton Orientation

## Core Features:

- Navbar Navigation: Display navigation bar at the top with links to Booklet, Organizing Committee, PKKMB Information, FAQ, Vision and Mission, Activities, Logo Meaning, Contact Information, Social Media, and Countdown.
- Event Countdown: Display countdown timer on the navbar showing time until the PKKMB event begins.
- Digital Booklet: Visually prominent 'Booklet' section, providing a flip-book like view of event details, rules, and guidelines. Rendered as a pop-up.
- Interactive FAQ: Interactive FAQ section to answer common questions from new students.
- Vision and Mission Display: Dedicated sections to showcase the vision and mission of the university.
- Detailed Activity Schedule: Schedule page detailing all activities on PKKMB days with interactive elements like maps, session descriptions, and speaker bios.
- Chatbot Assistant: Use a tool powered by LLM to give chatbot interface with contextual Q&A; answers based on PKKMB documents, helping with student queries dynamically.

## Style Guidelines:

- Primary color: #323e67, a soft blue inspired by clear skies above a castle, conveying hope and a fresh start (HSL: 211, 57%, 62%).
- Background color: #cd503e, a very light desaturated blue (HSL: 211, 20%, 97%) providing a clean, airy backdrop that enhances readability.
- Accent color: #f3f3e5, a light purple, complementary to the blue (HSL: 278, 32%, 52%), used for interactive elements to draw attention (buttons, links).
- Body font: 'PT Sans', a humanist sans-serif providing clarity and modernity suitable for schedules, descriptions, and general information.
- Headline font: 'Playfair', a modern serif bringing an element of refined elegance for titles, greetings, and key content headers.
- Incorporate icons designed as miniature castle elements to correlate with each navbar section: e.g., a booklet icon, a flag icon for vision/mission, and a gear icon for FAQs, enhancing navigation with thematic visual cues.
- Incorporate upward UX element reveal animations to bring in a fresh, dynamic, exciting feel when navigating sections of the app.
- Castle themed layout for visual consistency; with booklet UX elements animating to top from page corners.
